# Dota 2 Skins Manager

A set of scripts to manage, install, and update Dota 2 skins and mods.

### 💭 More about this project

- 📥 **InstallModsDota.bat** — automatically installs Dota 2 mods
- 🛠️ **FixMatchMaking.bat** — fixes matchmaking issues potentially caused by mods
- 🔤 **replace_dota_fonts.bat** — replaces Dota 2 fonts for a customized experience

### 🗂️ Project Structure

```
dota-2-skins-manager/
├── InstallModsDota.bat      — installs mods
├── FixMatchMaking.bat       — matchmaking fix
├── replace_dota_fonts.bat   — font replacement
├── DotaPath.txt             — path to your Dota 2 installation
└── LICENSE
```

---

### 🚀 Usage

```
1. Clone the repository
2. Make sure DotaPath.txt contains the correct path to your Dota 2 installation
3. Run the desired .bat file (as Administrator if required)
```
